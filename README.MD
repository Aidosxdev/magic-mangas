## 📖 About

**Magic Mangas** is a frontend project focused on creating a modern and user-friendly manga reading experience.

The project currently contains HTML pages and CSS styling for different sections of the platform.

## ✨ Features

- Manga catalog
- Popular manga section
- Manga archive
- Individual manga pages
- Shop interface
- Admin panel interface
- Responsive design improvements (in progress)

## 🛠️ Technologies

- HTML5
- CSS3

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Aidosxdev/magic-mangas.git
```

2. Open the project folder.

3. Launch `index.html` in your browser.
